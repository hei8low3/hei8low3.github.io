Last updated: 2026-11-16

What Google user data the app accesses

The app asks for one permission: youtube.upload, which lets it upload videos to the YouTube channel of the account that grants access. It does not read emails, contacts, files, viewing history or any other Google user data.

How the data is used

The permission is used only to upload videos that the app creates to the owner's own channel. The app is used only by its owner.

Storage and protection

The access credential (OAuth refresh token) is stored as a secret setting in the owner's private environment. It is never published, shared or written to source code.

Sharing

No Google user data is sold, shared, transferred or disclosed to anyone.

Retention and deletion

The credential is kept only while the app is in use. Access can be removed at any time at myaccount.google.com/permissions, after which the credential stops working and is deleted.

Contact

Questions can be sent through the GitHub profile of the owner (hei8low3).
